    Method and limits

    Source. The official Federal Register API (federalregister.gov/api/v1), which is public domain US government data and needs no key. Every item links to its page on federalregister.gov and its official PDF on govinfo.gov. Read the document itself before acting; this page is an index, not legal advice.

    Collection. A scheduled GitHub Action runs once a day, asks the API for documents published since the last run (minus a 3 day overlap to catch late indexing and corrections) for each watched agency, deduplicates by document number, keeps a rolling 365 days, and commits the result. Requests use small pages, a descriptive User-Agent and exponential backoff on HTTP 429 and 5xx.

    • Agency matching follows the API: a query for a department returns its sub-agencies too. Interior includes BSEE, BLM, BOEM, BIA, Fish and Wildlife and the rest. A joint rule appears under every watched agency that signed it.
    • Comment deadline is the API field comments_close_on. Not every notice has one, some deadlines are stated only in the document text, and a later document can extend or reopen a comment period. The closing view counts deadlines from the "As of" date through that date plus the window, inclusive.
    • Keyword search is a plain substring match on ASCII-lowercased text. Accented capitals are not folded (searching emissions does not match Émissions). No stemming: permit matches permits, but permits does not match permit.
    • Dates are Federal Register publication dates (ISO, Eastern time as published). The "As of" date defaults to today on your device, or to the snapshot date when the page runs from a snapshot.
    • Coverage is only the agencies in the repository's config.json. Abstracts are trimmed to 2,000 characters. Documents the API lists without a title, document number or valid publication date are skipped and logged.
    • Exports: cells that start with = + - @, tab or carriage return get a leading single quote so spreadsheets do not run them as formulas.
